# AGENTS.md — правила проекта «Сдача лабораторных работ»

## Гигиена тестов

1. **Тесты должны тестировать только бизнес-логику.** Не харнесс, не
   развёртывание, не CI/CD. Все тесты, не относящиеся к логике работы
   приложения, запрещены: гейты состава пакетов/файлов, статический анализ
   исходников, проверки README, build/CLI-метатесты, бенчмарки, тесты
   тестовой инфраструктуры (фабрик, фикстур, швов, лог-синков) — всё это
   в репозитории не держим.

2. **При правках, изменениях и удалениях функционала — обязательно проходить
   по тестам** и изменять или удалять неактуальные тесты. Тесты для
   функционала, от которого отказались, запрещены (пример: in-memory
   реализации хранилища удалены из приложения — вместе с ними удалены и их
   тесты; тестовые двойки живут в `tests/TestInfrastructure` и сами по себе
   предметом тестов не являются).

Справочно: тестовые двойки хранилища (in-memory) — общая библиотека
`tests/TestInfrastructure`; тестовые хосты зон и юнит-тесты подменяют ею
регистрации PostgreSQL (`InMemoryTestStorage.Register`). Единственная зона
на реальной БД — `tests/integration/B-23` (требует поднятого кластера из
`src/api/db/README.md`).
