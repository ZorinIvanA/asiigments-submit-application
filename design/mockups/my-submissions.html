Статичный макет SCR-010 «Сдача работ» студента (/my-submissions) — design 3.2 по spec 3.2 (FR-016): своя строка только для чтения; селектор семестров — семестры, в которых есть лабораторные (GET /semesters), по умолчанию НАИМЕНЬШИЙ из возвращённых (сид: 1); колонки «Лаб 1..N» с парами подколонок «Сдача»/«Защита» у КАЖДОЙ работы независимо от defenseRequired (ASM-010; у №3 признак выключен — строка «Защита» в карточке всё равно есть); даты дд.мм.гггг, пустая дата — ПУСТАЯ ЯЧЕЙКА БЕЗ ПРОЧЕРКА. Состояние «без группы» (hasGroup=false) — постоянный жёлтый баннер вместо таблицы, селектор семестра остаётся. Вырожденные состояния: нет семестров с работами (GET /semesters пуст, студент в группе) — селектор пуст и заблокирован, сообщение «Нет семестров с работами» (ISS-108/ASM-015; заглушка «Нет данных» из дизайна 3.0 не применяется — ISS-116); «без группы И нет лабораторных» — приоритет у предупреждения, сообщение не дублируется (решение дизайна). Мобильные ошибки (<768px) — красный inline-блок в фиксированной области под шапкой (экран без формы — ISS-106/AR-013), автозакрытие 5 с + × (FR-021).
