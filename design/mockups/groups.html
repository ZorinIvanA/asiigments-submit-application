Статичный макет SCR-011 «Группы» (/groups) и SCR-012 «Карточка группы» (/groups/:id) — design 3.2 по spec 3.2 (FR-017): список групп (упорядочен по названию по возрастанию без учёта регистра — порядок мока), диалоги создания/переименования/удаления, состав группы с исключением и пагинацией по 10 студентов. Кнопки подтверждающих диалогов — «Yes»/«No» дословно: удаление группы (FR-017, исключение NFR-004 из русских текстов) и исключение студента (решение дизайна — единообразно с FR-014/FR-017). Успехи — зелёные «Сохранено»/«Удалено» (FR-021); ошибки на мобильном — inline-блок в фиксированной области под шапкой (/groups, /groups/:id — экраны без формы, ISS-106/AR-013), автозакрытие 5 с.
