Статичный макет SCR-009 «Сдача работ» (/submissions) — design 3.2 по spec 3.2 (FR-015): селекторы «Группа» (по умолчанию — первая группа списка, упорядоченного по названию по возрастанию без учёта регистра, порядок задаёт мок; сид: «ИК-221») и «Семестр» (семестры, в которых есть лабораторные, из GET /semesters; по умолчанию — НАИМЕНЬШИЙ из возвращённых; сид: 1). Двухуровневая шапка «Лаб N» → подколонки «Сдача»/«Защита» — пара у КАЖДОЙ работы независимо от defenseRequired (ASM-010/OQ-007; у лабораторной №3 признак «Нужна защита» выключен — колонка «Защита» всё равно выводится и доступна для ввода). Даты дд.мм.гггг; пустая дата — ПУСТАЯ ячейка БЕЗ ПРОЧЕРКА. Выбор/очистка даты → SubmissionsService.update (upsert по паре studentId+labId — ISS-109), клиент всегда передаёт актуальные значения обеих дат (null = сброс; ASM-013). Календарь — русская локаль, переключение месяцев. Пагинация по 5 студентов. Вырожденные состояния: пустая группа — пустая таблица «В группе нет студентов», подпись «Показать записи с 1 по 0 из 0»; нет семестров с работами — селектор пуст и заблокирован, подпись «Нет семестров с работами» (ISS-108/ASM-015), таблица не отображается; нет групп — селектор пуст и заблокирован, подпись «Нет групп», таблица не отображается. Мобильные ошибки (<768px) — красный inline-блок фиксированно под шапкой (экран без формы — ISS-106/AR-013), автозакрытие 5 с + × (FR-021).
