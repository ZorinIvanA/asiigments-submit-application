Статичный макет SCR-013 «Доступ» (/access) — design 3.2 по spec 3.2 (FR-018): поиск по ФИО/логину/email без учёта регистра, фильтр «Без группы», таблица студентов (порядок мока — ФИО ↑, затем логин; поиск/фильтр порядок не меняют), группа меняется селектором в строке (включить / перевести / исключить), пагинация по 10 (сид: 32 студента, 4 страницы; для статичности показаны 3 строки). Поле поиска ограничено 200 символами (maxlength — контракт StudentsService.getList отклоняет search длиннее 200 символов ошибкой 400, ASM-018/SEC-001; клиент передаёт только корректные параметры, ошибка из UI недостижима). У student03 — состояние сохранения (500–800 мс мока, FR-003/NFR-001). Ошибки на мобильном — inline-блок в фиксированной области под шапкой (экран без формы, ISS-106/AR-013), автозакрытие 5 с (FR-021).
